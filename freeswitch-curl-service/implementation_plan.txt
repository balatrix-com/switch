# Live Calls v2: Redis-Backed ESL Polling with Idle Shutdown

ESL poller writes live call data to Redis every 3s. NestJS reads from Redis directly. Poller auto-sleeps after 10 minutes of no consumers, wakes when someone opens the dashboard.

No kill/hangup action.

## Architecture

```
                          ┌─────────────────────────┐
                          │  FreeSWITCH ESL :8021   │
                          └──────────┬──────────────┘
                                     │ show calls/channels as json
                          ┌──────────▼──────────────┐
                          │  esl_poller.py (pm2)     │
                          │  polls every 3s          │
                          │  idle shutdown @ 10 min  │
                          └──────────┬──────────────┘
                                     │ SET livecalls:data (TTL 10s)
                          ┌──────────▼──────────────┐
                          │  Redis 127.0.0.1:6379   │
                          └──────────┬──────────────┘
                                     │ GET livecalls:data
                                     │ SET livecalls:wake (TTL 600s)
                          ┌──────────▼──────────────┐
                          │  NestJS backend :3100    │
                          │  enriches with PG data   │
                          │  GET /api/live-calls     │
                          └─────────────────────────┘
```

### Idle Mechanism Flow

```
1. No one viewing dashboard
   → livecalls:wake key expires (TTL 600s = 10 min)
   → poller detects missing key, enters sleep mode (checks every 30s)
   → zero ESL load, zero Redis writes

2. Admin opens Live Calls page
   → NestJS GET /api/live-calls
   → NestJS sets livecalls:wake with TTL 600s
   → poller sees key on next 30s check, resumes 3s polling
   → data appears within ~3s

3. Admin closes page / stops polling
   → livecalls:wake TTL counts down
   → after 10 min of no requests → poller sleeps again
```

### 2. ESL Poller (new Python worker)

#### [NEW] `freeswitch-curl-service/esl_poller.py`

Standalone pm2 process. Reuses existing `esl_client.py` for ESL communication.

```python
# Pseudocode — actual implementation will be clean and minimal

loop:
    if redis.exists("livecalls:wake"):
        data = esl_client.live_calls()          # uses existing EslClient
        redis.set("livecalls:data", json(data), ex=10)
        sleep(3)
    else:
        sleep(30)                               # idle — just checking for wake key
```

- **Reads**: `ESL_HOST`, `ESL_PORT`, `ESL_PASSWORD`, `REDIS_URL` from `.env`
- **Writes**: `livecalls:data` key (JSON, 10s TTL as safety net)
- **Checks**: `livecalls:wake` key to decide active vs idle
- **Dependencies**: `redis` Python package (only new dep)
- **pm2 name**: `esl-poller`

#### [MODIFY] `freeswitch-curl-service/.env.example`

Add:
